# RED テスト — writing-skills テスト結果保存先の追加

**日時:** 2026-05-26
**対象スキル:** writing-skills（既存スキル編集）
**変更内容:** スキルテスト結果を `docs/superpowers/skill-tests/` に保存する指示の追加
**フェーズ:** RED（スキル編集前のベースライン）

---

## シナリオ

エージェントに以下を質問した：

1. REDテスト実施後、テスト結果ファイルをどこに保存するか？
2. GREENテスト実施後、テスト結果ファイルをどこに保存するか？
3. テスト中に生成されたファイル（例: `docs/rules/project-rules.md`）はどこに保存するか？
4. テスト結果ファイルの命名規則は何か？

また、「my-new-skill」というスキルの2026-05-26付けREDテストが完了したとして、保存先パスとファイル内容をシミュレートさせた。

## サブエージェントの出力（要約）

- 4問すべてについて「**スキルファイルには記載されていない（not specified in the skill）**」と回答
- 保存先・命名規則・フォーマットはすべてリポジトリの既存ファイル（`docs/superpowers/skill-tests/` ディレクトリ）を参照することで推測した
- スキルドキュメント自体には何も指示がないため、エージェントはリポジトリの慣例を読み解いて答えた

## 判定

**FAIL** — 以下の問題を確認：

- ❌ 保存先ディレクトリがスキルに記載されていない
- ❌ ファイル命名規則（`{date}-{skill-name}-{phase}.md`）がスキルに記載されていない
- ❌ テスト中生成ファイルの保存指示がスキルに記載されていない
- ❌ ファイルフォーマット（テンプレート）がスキルに記載されていない
- ❌ チェックリストに保存タスクが含まれていない
