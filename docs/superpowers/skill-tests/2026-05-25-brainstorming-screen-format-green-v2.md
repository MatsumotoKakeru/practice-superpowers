## シナリオ

「ユーザープロフィール編集画面」のブレインストーミングが完了したと仮定し、設計書を書き出す。  
画面は表示名・メールアドレスの編集、保存ボタン・キャンセルボタンを持つ。

## サブエージェントの出力

```markdown
# ユーザープロフィール編集画面 設計書

## 画面概要

ログイン中のユーザーが自分の表示名（display name）とメールアドレスを編集できる画面。Save ボタンで変更を保存し、Cancel ボタンで変更を破棄して前の画面へ戻る。

## URL

/users/[id]/edit

## 項目一覧

- 表示名（必須・テキスト入力・最大50文字）：ユーザーの表示名。空欄不可。50文字以内。
- メールアドレス（必須・テキスト入力・文字制限なし）：ユーザーのメールアドレス。空欄不可。有効なメールアドレス形式であること。

## イベント処理

- 保存ボタン押下：
  - チェック：必須項目が空欄の場合、またはメールアドレスが不正な形式の場合はエラーメッセージを表示して送信しない
  - 正常：入力内容を保存してプロフィール画面へ遷移する
  - エラー：サーバーエラーの場合はエラーメッセージを画面上部に表示する
- キャンセルボタン押下：入力内容を破棄して前の画面へ戻る
```
