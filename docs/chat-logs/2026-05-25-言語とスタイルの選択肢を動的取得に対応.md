# 2026-05-25 言語とスタイルの選択肢を動的取得に対応

## やり取り

**ユーザー:** 言語とスタイルが選択できない

**Claude:** 問題を調査しました。react-hook-form の register() は非同期で読み込まれる select options に対応していません。マウント時に options がなければ value が無視されます。Controller コンポーネントに切り替えることで、React が value={field.value} を毎レンダーに適用するため、options が後から届いても正しい値が表示されます。EditSnippetForm.tsx の language と style の select を register() から Controller に変更しました。

---

**ユーザー:** 動的に取得でお願いします

**Claude:** Django側にGET /choices/エンドポイントを追加し、Next.js側にuseSnippetChoicesフックを作成しました。フックはSWRでデータをキャッシュし、languagesとstylesの配列を返します。EditSnippetFormとNewSnippetFormの両方でこのフックを使用するように更新しました。
