**Claude:** **PreCompact フックの動作:**

```
コンテキストが満杯に近づく
        ↓
Claude Code が自動コンパクトを実行しようとする
        ↓
PreCompact フック発火（コンパクト実行前）
        ↓
フックのコマンドが以下を出力:
  {"systemMessage": "⚠️ コンパクト前に /save-chat-log を実行してください！"}
        ↓
Claude がユーザーに警告を伝える
        ↓
ユーザーが /save-chat-log を手動実行

```

**メリット:**
- コンテキストが消える直前に気づける
- 毎ターン邪魔にならない（コンパクト前だけ）

**限界:**
- コンパクト以外のセッション終了（ターミナルを閉じる・`/clear`）はカバーできない
- スキル自体の実行はあくまで手動
