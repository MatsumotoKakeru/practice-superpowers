# スニペット管理フロントエンド 設計書

作成日: 2026-05-27
ブランチ: feature/snippet-management-frontend-v2

## 概要

Django REST Framework バックエンドと連携するスニペット管理 UI を Next.js App Router で実装する。
認証なし、全CRUD操作（一覧・詳細・新規作成・編集・削除）を提供する。

## アーキテクチャ

### ファイル構成

```
nextjs-practice/src/
├── app/
│   └── snippets/
│       ├── page.tsx          # 一覧画面
│       ├── new/
│       │   └── page.tsx      # 新規作成画面
│       └── [id]/
│           ├── page.tsx      # 詳細画面
│           └── edit/
│               └── page.tsx  # 編集画面
├── components/
│   └── snippets/
│       ├── SnippetCard.tsx   # 一覧の各スニペット表示
│       └── SnippetForm.tsx   # 新規作成・編集共用フォーム
├── hooks/
│   ├── useSnippets.ts        # 一覧取得（GET /snippets/）
│   ├── useSnippet.ts         # 詳細取得（GET /snippets/{id}/）
│   ├── useCreateSnippet.ts   # 作成（POST /snippets/）
│   ├── useUpdateSnippet.ts   # 更新（PUT /snippets/{id}/）
│   └── useDeleteSnippet.ts   # 削除（DELETE /snippets/{id}/）
└── lib/
    └── api.ts                # fetch ラッパー（各フックから呼ぶ）
```

### データフロー

- 全ページ `'use client'` の Client Component
- `lib/api.ts` で DRF の `/snippets/` エンドポイントを叩く fetch 関数を定義
- データ取得系フック（`useSnippets`, `useSnippet`）は `loading` / `data` / `error` 状態を返す
- ミューテーション系フック（`useCreateSnippet`, `useUpdateSnippet`, `useDeleteSnippet`）は実行関数と `loading` / `error` 状態を返す

### バックエンド連携

- API ベース URL: DRF の `/snippets/` エンドポイント
- ページング: DRF レスポンスの `count` / `next` / `previous` フィールドを利用
- 認証: なし

## 画面設計

### 1. スニペット一覧画面

#### 画面概要
登録済みのスニペット一覧をページング付きで表示する。詳細・新規作成への導線となるメイン画面。

#### URL
`/snippets?page=1`

#### 項目一覧
- スニペット一覧（表示専用）：タイトル・言語を一覧表示。`useSnippets` フックで取得。
- 新規作成ボタン（任意・ボタン）：一覧上部に配置。
- 各スニペットの詳細リンク（表示専用）：タイトルをクリックで詳細画面へ。
- 各スニペットの削除ボタン（任意・ボタン）：一覧上で削除できる。
- ページングコントロール（表示専用）：前へ・次へボタン、現在のページ番号を表示。DRF のレスポンス（`count` / `next` / `previous`）を利用する。

#### イベント処理
- 新規作成ボタン押下：`/snippets/new` に遷移する。
- タイトルリンク押下：`/snippets/[id]` に遷移する。
- 削除ボタン押下：
  - チェック：削除確認ダイアログを表示する
  - 正常：`useDeleteSnippet` を呼び出し、成功後に現在ページを再取得して表示を更新する
  - エラー：画面上部にエラーメッセージを表示する
- 前へ／次へボタン押下：URL の `?page=` パラメータを更新し、該当ページのデータを取得する
- ローディング中：スピナーまたは「読み込み中...」テキストを表示する
- データなし：「スニペットがありません」メッセージを表示する

---

### 2. スニペット詳細画面

#### 画面概要
選択したスニペットの全情報を表示する。編集・削除への導線となる画面。

#### URL
`/snippets/[id]`

#### 項目一覧
- タイトル（表示専用）：スニペットのタイトル。
- 言語（表示専用）：プログラミング言語名。
- スタイル（表示専用）：ハイライトスタイル名。
- 行番号表示（表示専用）：有効/無効を表示。
- コード（表示専用）：DRF が生成したハイライト済み HTML（`highlighted` フィールド）を表示する。
- 編集ボタン（任意・ボタン）：編集画面への導線。
- 削除ボタン（任意・ボタン）：このスニペットを削除する。
- 一覧に戻るリンク：一覧画面への導線。

#### イベント処理
- 編集ボタン押下：`/snippets/[id]/edit` に遷移する。
- 削除ボタン押下：
  - チェック：削除確認ダイアログを表示する
  - 正常：`useDeleteSnippet` を呼び出し、成功後に `/snippets` に遷移する
  - エラー：画面上部にエラーメッセージを表示する
- 一覧に戻るリンク押下：`/snippets` に遷移する。
- ローディング中：スピナーまたは「読み込み中...」テキストを表示する
- スニペットが存在しない（404）：「スニペットが見つかりません」メッセージを表示する

---

### 3. 新規作成画面

#### 画面概要
新しいスニペットを登録する画面。`SnippetForm` コンポーネントを使用する。

#### URL
`/snippets/new`

#### 項目一覧
- タイトル（任意・テキスト入力・最大100文字）：スニペットの名前。未入力可。
- コード（必須・テキストエリア・最大2,000文字）：登録するコードの内容。空欄不可。
- 言語（必須・セレクトボックス・デフォルト: python）：プログラミング言語を選択。DRF の選択肢に従う。
- スタイル（必須・セレクトボックス・デフォルト: friendly）：ハイライトスタイルを選択。
- 行番号表示（任意・チェックボックス・デフォルト: オフ）：行番号を表示するかどうか。
- 保存ボタン（必須・ボタン）：入力内容を保存する。
- キャンセルリンク：入力内容を破棄して一覧に戻る。

#### イベント処理
- 保存ボタン押下：
  - チェック：コードが空欄の場合はフィールド下にエラーメッセージを表示して送信しない
  - チェック：コードが2,000文字を超える場合はフィールド下にエラーメッセージを表示して送信しない
  - 正常：`useCreateSnippet` を呼び出し、成功後に `/snippets` に遷移する
  - エラー：サーバーエラーの場合は画面上部にエラーメッセージを表示する
- キャンセルリンク押下：
  - チェック：入力済み項目がある場合は「保存していません。一覧に戻りますか？」確認ダイアログを表示する
  - 正常：`/snippets` に遷移する
  - キャンセル：ダイアログを閉じて画面に留まる

---

### 4. 編集画面

#### 画面概要
既存スニペットの内容を編集して保存する画面。`SnippetForm` コンポーネントを新規作成と共用する。

#### URL
`/snippets/[id]/edit`

#### 項目一覧
- タイトル（任意・テキスト入力・最大100文字）：既存のタイトルを初期値として表示。
- コード（必須・テキストエリア・最大2,000文字）：既存のコードを初期値として表示。空欄不可。
- 言語（必須・セレクトボックス・デフォルト: 既存値）：既存の言語を初期値として表示。
- スタイル（必須・セレクトボックス・デフォルト: 既存値）：既存のスタイルを初期値として表示。
- 行番号表示（任意・チェックボックス・デフォルト: 既存値）：既存の設定を初期値として表示。
- 保存ボタン（必須・ボタン）：変更内容を保存する。
- キャンセルリンク：変更を破棄して詳細画面に戻る。

#### イベント処理
- 保存ボタン押下：
  - チェック：コードが空欄の場合はフィールド下にエラーメッセージを表示して送信しない
  - チェック：コードが2,000文字を超える場合はフィールド下にエラーメッセージを表示して送信しない
  - 正常：`useUpdateSnippet` を呼び出し、成功後に `/snippets/[id]` に遷移する
  - エラー：サーバーエラーの場合は画面上部にエラーメッセージを表示する
- キャンセルリンク押下：
  - チェック：変更済み項目がある場合は「保存していません。戻りますか？」確認ダイアログを表示する
  - 正常：`/snippets/[id]` に遷移する
  - キャンセル：ダイアログを閉じて画面に留まる
- ローディング中（初期データ取得時）：スピナーまたは「読み込み中...」テキストを表示する
- スニペットが存在しない（404）：「スニペットが見つかりません」メッセージを表示する

## バリデーションルール（フロントエンド）

| フィールド | 必須 | 最大文字数 | 備考 |
|-----------|------|-----------|------|
| タイトル | 任意 | 100文字 | バックエンド仕様に準拠 |
| コード | 必須 | 2,000文字 | フロントエンド独自制限 |
| 言語 | 必須 | - | デフォルト: python |
| スタイル | 必須 | - | デフォルト: friendly |
| 行番号表示 | 任意 | - | デフォルト: オフ |
